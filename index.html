Capture test

Screenshot Experiment

The screen is an output device. A screenshot is another image file.

  1. Observe the HDR tile directly on the display.
  2. Take a normal macOS screenshot.
  3. Open the screenshot beside the live webpage.
  4. Compare whether the brightness difference was flattened or tone-mapped.

What this test measures

A normal capture often records composited pixel values after tone mapping. It does not record the physical light that reached your eye.

DOM or canvas capture would be less useful here: canvas may convert or tone-map the HDR file, and JavaScript cannot measure emitted nits.

Skeptic’s checklist

How to tell this from a CSS trick

  • Inspect the computed values above: no filter, opacity change, blend mode, transform, shadow, or animation.
  • Use isolation mode: every file occupies the same 160 × 160 position.
  • Switch the surround to white: physical luminance headroom survives a contrast change.
  • Download the files and run the verification script: the difference lives in transfer and gamut metadata.
